# Limites de Divulgação

Esta seção define os limites entre o portfólio público e o CDC 2.0 operacional.

## O que É DIVULGADO

- Arquitetura geral e design
- Fluxos de orquestração
- Tecnologias utilizadas
- Estado de desenvolvimento
- Estatísticas de progresso
- Documentação técnica

## O que NÃO É DIVULGADO

### Código e Dados
- ❌ Código-fonte operacional dos projetos
- ❌ Bancos SQLite operacionais (`CDC.db`, `mattpocock.db`)
- ❌ Arquivos `.env` ou de configuração sensível

### Credenciais e Acesso
- ❌ Credenciais de API
- ❌ Chaves de acesso e credenciais
- ❌ Dados de autenticação
- ❌ URLs de endpoints privados

### Informações Pessoais
- ❌ Endereços de arquivos pessoais
- ❌ Caminhos de sessão privada
- ❌ Informações privadas de terceiros

### Histórico Git
- ❌ Histórico completo de commits privados
- ❌ Mensagens de commit com dados sensíveis

## Justificativa

A publicação serve apenas para **documentação profissional e apresentação**, não para **reprodução ou operação**. O CDC 2.0 permanece uma cópia operacional independente.
