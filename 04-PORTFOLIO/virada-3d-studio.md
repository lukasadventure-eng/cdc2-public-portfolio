# VIRADA 3D STUDIO

> **Status:** Ativo
> **Objetivo:** Jogo 3D interativo de educação financeira (Godot, pt-BR)

---

## 1. Identidade
VIRADA 3D STUDIO é um jogo 3D desenvolvido em Godot para simular um tabuleiro de educação financeira, com foco em vegetação e iluminação de rua.

## 2. Problema
Precisamos de uma experiência 3D interativa para ensinar finanças de forma envolvente, combinando jogos com educação.

## 3. Visão Arquitetural
- **Tabuleiro 3D:** Trilha base navegável com modelagem estrutural.
- **Vegetação e Iluminação:** Detalhamento de elementos naturais e iluminação urbana.
- **Acabamentos Arquitetônicos:** Beirais, cumeeiras, calhas.

## 4. Tecnologias
- Godot Engine (renderização 3D)
- GDScript (lógica de jogo)
- JSON (especificações técnicas)

## 5. Implementação e Evidências
- **Trilha base 3D:** Commit `9731290` com estrutura inicial.
- **Acabamentos implementados:** Beirais, cumeeiras, calhas.
- **Status atual:** Vegetação e iluminação de rua em andamento.
