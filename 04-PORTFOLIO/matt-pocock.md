> **Status:** Concluído

## 1. Identidade
Matt Pocock é um catálogo interativo de skills para desenvolvimento de agentes e sistemas, com foco em TypeScript, React e integração com frameworks de IA.

## 2. Problema
A necessidade de documentar, navegar e validar skills técnicas para uso em agentes de IA, evitando reinventar soluções e garantindo qualidade técnica.

## 3. Visão Arquitetural
- **Catalogação:** Banco de skills com metadados completos.
- **Busca/Recomendação:** Sistema de descoberta baseado em tags e dependências.
- **Self-test:** Cada skill possui teste de validação automatizado.

## 4. Tecnologias
- TypeScript
- React
- Ferramentas de desenvolvimento OpenCode
- Testes automatizados
