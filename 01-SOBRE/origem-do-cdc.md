# Origem do CDC 2.0

## Contexto Inicial

O **CDC 2.0** (*Coordenador Cognitivo*) nasceu como solução para uma necessidade fundamental: coordenar múltiplos projetos de desenvolvimento de software de forma autônoma, sem depender de supervisão humana constante.

## Evolução

### CDC 1.0 → CDC 2.0
A evolução ocorreu de forma iterativa:

1. **CDC 1.0:** Sistema monolítico de coordenação básica.
2. **CDC 2.0:** Refatoração em arquitetura modular, com separação clara de responsabilidades:
   - Memória persistente
   - Alternância inteligente de foco
   - Integração com OpenCode
   - Orquestração de agentes

## Princípios Fundamentais

- **Autonomia:** O sistema opera sem intervenção humana constante.
- **Persistência:** Memória contextual entre sessões via SQLite.
- **Escalabilidade:** Arquitetura modular para adição de novos projetos.
- **Resiliência:** Recuperação de execuções interrompidas.

## Data de Concepção

O CDC 2.0 foi concepido em **2026**, como evolução natural do fluxo de trabalho de desenvolvimento multiagente.
